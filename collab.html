Langkah-Langkah Collab Project Github:

  • 1.Fork repository utama keakun Github masing-masing
  • 2.Clone repository yang telah di-fork ke komputer lokal
  • 3.Buat branch baru untuk pekerjaan yang akan dilakukan
  • 4.Lakukan perubahan pada kode
  • 5.Commit dan push perubahan ke branch yang telah dibuat
  • 6.push branch ke repository fork di Github
  • 7.Buat Pull Request ke repository utama
  • 8.Tim lain akan meninjau pull request dan memberikan masukkan atau persetujuan
  • 9.Jika disetujui,pull request akan digabungkan ke repository utama
